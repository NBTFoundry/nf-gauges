### Fixed

- With the engine off, values iDrive marks as not available (65535 rpm, 1024 Nm, a pedal at 4095 %, a steering angle of 65535°) are no longer shown: those gauges show -- instead.
- TRANSMISSION no longer says rear-wheel drive on an xDrive car whose transfer case cannot be read: with Drivetrain on auto it asks you to set it in the settings.

### Good to know

- Needs NBT Manager 0.4.0 or later. NBT Manager 0.5.6 searches harder for the car's gateway, which engine values need.
